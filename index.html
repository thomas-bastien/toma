Backup & Help
How to keep your work safe — and share it with the team
ℹ️
This tracker has no server yet. Everything you enter is saved only in this browser, on this device. It isn't shared automatically between people, and it doesn't sync across your phone and computer — each one keeps its own copy.
💾 The 3 things to remember
1
Export regularly. Click ⬇ Export JSON (top-right, or the button below) to save a backup file of your data. Do it whenever you've made important changes.
2
Import to restore or move. Click ⬆ Import JSON and pick a backup file to load it onto another browser/device — or to share your state with someone else.
3
Export before you close if you made important changes — so nothing is lost.
🔄 Sharing with the team

Until real-time sync arrives, you share data by passing the backup file around:

  • To send your latest version: do an Export JSON and send the file.
  • To get someone's version: receive their file and do an Import JSON.
⚠️
Importing replaces all current data with the file's contents. Export your own copy first if you're not sure.
✅ A few good habits
  • Don't clear the browser history/cache for this site — it erases everything.
  • Avoid private / incognito mode (data isn't kept after you close it).
  • Real-time shared & synced data is coming soon.
